# Goon Compagnon

Web app iPhone (PWA) : tracker Destroy Dick December, techniques et sortie du porno. Design Liquid Glass, 100 % local, fonctionne hors ligne.

## Mise en ligne (GitHub Pages)

1. Crée un dépôt public `goon-compagnon` sur GitHub.
2. Upload tout le contenu de ce dossier à la racine (`index.html`, `manifest.webmanifest`, `sw.js`, dossier `icons`).
3. Settings > Pages > Source : `Deploy from a branch`, branche `main`, dossier `/ (root)`.
4. L'app est en ligne sur `https://<ton-pseudo>.github.io/goon-compagnon/` après une minute.

## Installation sur iPhone

Ouvre l'URL dans Safari > Partager > Sur l'écran d'accueil.

## Données

Tout est stocké dans le `localStorage` du téléphone. Aucun serveur. Export / import JSON depuis l'onglet Profil.
